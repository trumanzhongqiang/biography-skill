# 个人传记（biography-skill）🖊️

> 帮助普通人写个人传记：访谈式采集回忆、自动整理时间线、章节化成稿。
> 用户只需要聊天式地回忆人生，剩下的交给 AI。

每个人都值得被记录，但传记写作对普通人来说门槛太高——不知道怎么开头、记不住具体时间、一写就变成流水账。这个 Agent Skill 把「写传记」变成一场自然的对话：AI 扮演专业传记访谈者，像聊天一样引导你回忆人生中的关键时刻、重要人物与转折点，自动把零散回忆整理成时间线，最后组织成连贯、有温度的章节成稿。

## 功能特性

- **访谈式采集**：像专业传记作者一样，用有温度的一连串提问引导回忆，一次只问一个问题，从细节切入而非问卷式盘问
- **结构化整理**：自动把零散回忆按时间线归档，识别人物关系与主题线索，补全时间、地点；前后说法冲突时主动与你确认，绝不自行编补
- **章节化成稿**：按八章结构把素材组织成连贯章节，保留你自己的语言风格和情感色彩，拒绝干巴巴的流水账
- **渐进式写作**：支持随时中断、随时续写。人生很长，传记可以慢慢写
- **隐私本地优先**：所有素材都存在本地工作目录，敏感内容由你自己决定保留还是删除

## 快速开始

WorkBuddy 用户：

1. 下载本仓库的 `biography-skill.skill` 文件
2. 在 WorkBuddy 中加载该 `.skill` 文件
3. 说出触发词，例如：
   - 「启动个人传记」
   - 「帮我写传记」
   - 「帮我爸写一本传记」
4. 跟随 AI 的提问聊天式回忆；随时说「今天就到这里」，下次接着说「续写传记」即可继续
5. 说「整理成稿」开始章节化写作，每章写完会给你确认后再定稿

其他 AI 助手：直接让助手读取 `skill/biography-skill/SKILL.md` 并按其中的指令工作即可。

## 它是怎么工作的

```
聊天回忆 → 访谈式采集（问题库引导，保留原话）
        → 结构化整理（时间线 + 人物表 + 冲突确认）
        → 传记蓝图（章节划分，与你确认）
        → 章节化成稿（每章确认后定稿，支持无限续写）
```
