# 章节结构模板

传记成稿的结构参考。每章 2000~4000 字，从场景切入，用细节说话。

## 全书结构（默认八章，可按素材增减合并）

| 章 | 主题 | 时间范围 | 核心素材 |
|----|------|----------|----------|
| 第一章 | 出生与家世 | 出生前后 | 家族背景、名字由来、时代环境 |
| 第二章 | 童年时光 | ~12 岁 | 住所、玩伴、学校、家庭氛围 |
| 第三章 | 求学岁月 | 学生时代 | 关键老师、转折事件、青春记忆 |
| 第四章 | 走出家门 | 毕业~立业前 | 第一份工作、初到异地、闯荡 |
| 第五章 | 立业 | 职业生涯 | 事业起落、得意与艰难、师友 |
| 第六章 | 爱情与家庭 | 成家~养育 | 相识、婚礼、孩子、家庭传统 |
| 第七章 | 风雨与转折 | 低谷期 | 分水岭事件、支撑自己的人 |
| 第八章 | 回望 | 近年~当下 | 信念、传承、想说的话 |

## 单章内部结构模板

每章按 3~5 个小节展开，每个小节遵循「场景 → 事件 → 人物 → 内心」四步：

1. **场景切入**：用具体时间、地点、天气、物件开头，一句话把读者拉进去。
2. **事件展开**：讲发生了什么，按时间顺序，穿插当时人物的对话（用用户记忆中的原话）。
3. **人物登场**：本章涉及的重要人物，首次出场给出姓名、与用户的关系、一两句外貌或口头禅描写（素材均取自 `characters.md`）。
4. **内心落点**：以用户的感受或后来的感悟收束小节，一两句即可，不说教。

## 章首与章尾规范

- **章首**：不写「本章讲述……」这类说明文字。直接从场景开头，或引一句用户访谈中的原话作题记。
- **章尾**：留一个通向下一章的钩子——一个未解的悬念、一次告别、一个决定。

## 文风规范

- **保留个人色彩**：用户的口头禅、方言词、惯用比喻保留在对话和直接引语中。
- **具体代替形容词**：不写「日子很苦」，写「一个月吃不上两回肉」。
- **五感细节**：每章至少出现 2~3 处感官细节（声音、气味、颜色、触感）。
- **时代锚点**：每个年代首次出现时给一个时代背景句（如「那年头粮票还没取消」），帮助读者定位。
- **数字具体化**：工资、价格、路程给具体数字，数字是记忆最牢的东西。

## 定稿检查清单

每章交付前自查：

- [ ] 事实与时间线一致，无未确认的时间/人名（查 `open-questions.md` 应为空）
- [ ] 涉及隐私的段落已提醒用户确认
- [ ] 没有编造的用户未提及的细节
- [ ] 对话引语均来自素材记录
- [ ] 章尾有通往下一章的钩子
